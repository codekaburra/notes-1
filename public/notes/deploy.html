這個站怎麼運作、怎麼部署

2026-09-06

語言切換

兩種語言的內容都在同一份 HTML 裡，用 data-l="zh" 跟 data-l="en" 標記，靠 CSS 藏掉另一邊：

html[data-lang="zh"] [data-l="en"] { display: none; }
html[data-lang="en"] [data-l="zh"] { display: none; }

按鈕做的事只有一件：改 <html> 上的 data-lang，然後寫進 localStorage，換頁時會記得。

另外在 <head> 裡有一小段 inline script，在畫面繪製之前就把 data-lang 設好。沒有這段的話，載入瞬間會先閃一下預設語言才跳走。

加一則新筆記

  1. 複製這個檔案到 public/notes/新名字.html。
  2. 改掉 <title> 跟 <body> 上的 data-title-zh / data-title-en。
  3. 兩個 data-l 區塊各寫一種語言。
  4. 回到 public/index.html，在 <ul class="notes"> 加一個 <li>。

部署到 GitHub Pages

推上 main 就會自動發布，設定在 .github/workflows/pages.yml。首次要去 repo 的 Settings → Pages → Source 選 GitHub Actions。

注意：repo 要設成 public 才免費。private repo 的 Pages 需要付費方案。而且就算 repo 是 private，發布出去的網站本身仍然是公開可存取的。

部署到 Cloudflare Workers

npx wrangler login   # 只要做一次
npx wrangler deploy

設定在 wrangler.jsonc，靜態站不需要 Worker 程式碼，只要指定 assets.directory 就好。

為什麼路徑都是相對的

GitHub Pages 的專案站掛在 使用者名稱.github.io/repo名/ 這種子路徑下。所以 /assets/style.css 這種絕對路徑會全部 404。全部寫成 ./assets/… 或 ../assets/…，兩邊才都能跑。

同理，連結一律帶 .html 副檔名。Cloudflare 可以省略，GitHub Pages 不行。

How this site works and ships

2026-09-06

The language toggle

Both languages live in the same HTML file, tagged with data-l="zh" and data-l="en". CSS hides the other one:

html[data-lang="zh"] [data-l="en"] { display: none; }
html[data-lang="en"] [data-l="zh"] { display: none; }

The buttons do exactly one thing: set data-lang on <html> and save it to localStorage, so the choice survives navigation.

A small inline script in <head> sets data-lang before first paint. Without it you'd see a flash of the wrong language on every load.

Adding a note

  1. Copy this file to public/notes/your-name.html.
  2. Update <title> and the data-title-zh / data-title-en attributes on <body>.
  3. Write one language in each data-l block.
  4. Add an <li> to <ul class="notes"> in public/index.html.

Deploying to GitHub Pages

Pushing to main publishes automatically via .github/workflows/pages.yml. Once, in the repo: Settings → Pages → Source → GitHub Actions.

The repo must be public to stay free. Pages from a private repo needs a paid plan — and the published site is still publicly reachable either way.

Deploying to Cloudflare Workers

npx wrangler login   # once
npx wrangler deploy

Config lives in wrangler.jsonc. A static site needs no Worker script at all — just assets.directory.

Why every path is relative

GitHub Pages project sites are served from a subpath: username.github.io/repo/. Absolute paths like /assets/style.css 404 there. Using ./assets/… and ../assets/… keeps the same files working on both hosts.

Same reason links always carry the .html extension: Cloudflare can drop it, GitHub Pages can't.
